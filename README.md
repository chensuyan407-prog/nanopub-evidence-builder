# nanopub-evidence-builder 0.1.0 — submission bundle for 阅读14｜Nanopublication

Skill that turns the conclusions of a scientific PDF into **nanopublications**: one atomic, checkable assertion
per record, bound to the smallest verbatim evidence (page, block, sentence id, line boxes or table cell) and to
source provenance (title, authors, year, DOI / arXiv id + version, PDF SHA-256), checked by 26 deterministic
quality rules and exported as JSON, TriG, N-Quads and JSON-LD.

| path | content |
|---|---|
| `submission/` | **the Skill** (`SKILL.md`, `scripts/`, `vocab/`, `examples/`, `README.md` = field dictionary, method, limits) |
| `skills/SKILL.md` | copy of the Skill entry file |
| `src/reproduce.py` | reruns the whole self-evaluation (≈15 s, CPU) |
| `tests/` | labelled drafts (`eval/*/draft.json`, generated by `make_eval_drafts.py` / `make_holdout_draft.py`), `run_eval.py`, test PDFs (public arXiv files), `FREEZE_holdout.sha256` |
| `execution/` | `run.log`, `results/metrics.json`, `results/metrics_at_freeze.json`, `results/eval_rows.json`, per-paper outputs incl. `evidence_previews/*.png` |
| `arm_manifest.json`, `characterization.json`, `trace/trace.jsonl` | ARM bundle metadata |

## Reproduce

```bash
pip install -r requirements.txt   # pymupdf, numpy (+ optional rdflib for the TriG parse check)
python src/reproduce.py
```

## Results (author-chosen public papers; not the platform's fixed cases)

| set | assertions | planted defects detected | clean not failed | clean evidence boxed at quote / cell |
|---|---:|---:|---:|---:|
| dev (ResNet, Transformer, BatchNorm; rules tuned on it) | 35 | 21/21 | 14/14 | 14/14 |
| held-out (Kaplan 2020), code frozen | 12 | 6/7 | 5/5 | 5/5 |
| held-out after the post-freeze fix | 12 | 7/7 | 5/5 | 5/5 |

Baselines on the same 28 defects: exporting without checks catches 0; a "quote exists in the PDF" check catches 4.
Metadata on the 4 papers: title, year, arXiv id, version all exact; authors recall 1.0, precision 1.0 (held-out
paper 0.83 before the fix). Exports round-trip (rdflib parses the TriG with the same quad count); same draft →
identical N-Quads. Robustness: encrypted PDF, no PDF, missing case.json → `failed` with reason; image-read evidence →
`partial` with the record listed for human review.

The held-out miss (a compound claim joined by ", and" + a verb outside the list) shows the main limit:
the rules are lexical. See `submission/README.md` → Limits.
